# Plan: build 5.D On input (2026-11-01)

The rules are in [rules/5d-on-input.md](../rules/5d-on-input.md) (0.2.0)
and the tasks in [rules/5d-build-tasks.md](../rules/5d-build-tasks.md).
This plan is the order of work. Why 5.D: mechanical, no scanner covers it,
and it reuses the walk, replays and 4.A's observer
([research/2026-10-31-tt-coverage-map.md](../research/2026-10-31-tt-coverage-map.md)).
After it, the other form tests (5.F, 5.G and the 5.A/5.C leftovers) may fit
better than 9.A, which moved to the multi-page batch
([2026-11-01-multi-page.md](2026-11-01-multi-page.md)).

## Steps

1. **Shared observer.** Move `observe`, `snapshot` and `Effect` from
   `checks/t4a.py` to `src/a11y_assist/observe.py`; 4.A and 4.B import it.
   No behavior change: the full suite stays green.
2. **Evidence the rules need.** Field kinds on stops (radio with its group,
   switch, combobox, slider, spinbutton, disabled, read-only); form fields in the DOM
   inventory; the init script's submit log. Unit tests on `no_trap.html`
   and small custom pages.
3. **Early stop over `FIELD_MAX`** in the pipeline, beside `WalkTooLong`,
   with a time estimate and `no_time_limit` lifting the cap. Test as
   `tests/test_time_budget.py` does.
4. **Fixtures.** Vendor the five Baseline Alignment TC10.C cases with
   `tests/fixtures/baseline/sync_baseline.py` and load each in Chrome; write
   the custom pages F01–F13 in `tests/fixtures/5d/`. Expected outcomes go
   in `tests/test_fixtures_5d.py`, never in a page.
5. **`checks/t5d.py`.** Pass F, the rows as `engine.Row` tables copied from
   the spec, J1–J3, the plain sentences; register it in
   `checks/__init__.py`. Run fixtures with `tests/harness.py run_check()`
   and scripted answers.
6. **Time.** `uv run python evals/time_budget.py budget/benefits-form.html
   budget/agency-home.html` with 5.D included; set the per-field cost in the
   early-stop estimate from it, and lower `FIELD_MAX` if pages take too
   long.
7. **Judge eval.** Add 5.D to `evals/judge_eval.py`'s cases; one subagent
   answers all packets (`evals/README.md`). Fix every mismatch in the
   question or its input.
8. **Spec to 1.0.0.** Make the spec match the code exactly, trim the build
   tasks to what is left (Windows checks), and update `evaluation.md` and
   the deck (a new TT test), the ROADMAP, and `docs/solutions/` with any
   lesson that cost time.

Run `uv run pytest -n 8` and ruff before each commit; commit and push after
each step.
